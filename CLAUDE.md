This project processes construction drawing PDFs into indexed, queryable data and runs quantity takeoffs. Built by Hamza Jabbar at AutoConst.

## Skills in this repo

### 1. Drawing Analyzer (SKILL.md in root)
Processes a drawing set into indexed files. Always run this first on a new project.

Splits the PDF, extracts text and vector data, classifies every sheet, builds the symbol library and cross-reference matrix. Stores results in `indexes/` and `sheets/`.

Activation:
```
Run drawing analyzer on my construction drawings
```

### 2. Construction Takeoff (skills/construction-takeoff/SKILL.md)
Runs a quantity takeoff using the indexed drawing data. Requires Drawing Analyzer to have run first.

Counts elements, calculates secondary quantities (concrete, formwork, reinforcement), marks up drawings for audit, exports to Excel.

Activation:
```
Use my construction-takeoff skill.
Scope: foundations only. Page 2 only.
Output to outputs/[project]-foundation-takeoff.xlsx
```

### 3. PDF Markup (skills/pdf-markup/SKILL.md)
Bulk markup operations on PDFs. No Bluebeam Max required.

Stamps, text edits, colour changes, markup extraction. Does the same bulk markup work the Bluebeam Claude integration does on a standard Claude subscription.

Activation:
```
Use my pdf-markup skill.
Add "Not for Construction" stamp to all sheets in the drawing set.
```

## Query protocol after Drawing Analyzer has run

When answering any drawing question:

1. Read `indexes/drawings.md` first — understand the drawing set structure
2. Read `indexes/sheet-classification.md` — find the relevant sheet
3. Read `indexes/cross-reference.md` — check if other sheets are referenced
4. Read `indexes/symbol-library.md` — confirm symbol meanings
5. Read the target sheet `.txt` file in `sheets/` — vector and text data
6. View the target sheet `.png` in `sheets/` — visual confirmation
7. Run polygon extraction via `scripts/extract_polygons.py` only if area takeoff is needed

This replaces processing 60,000 to 70,000 tokens of raw PDF with 5,000 to 8,000 tokens of targeted reading.

## Secondary quantity ratios

Default ratios for calculating concrete volumes, formwork areas, and reinforcement weights from primary element counts are in `references/structural-secondary-quantities.md`.

These are used by the Construction Takeoff skill. Override them by adding your firm's actual ratios to your business context (Notion / Google Drive / connected data source).

## Operating rules

1. Never modify files in `indexes/` or `sheets/` manually. These are generated by the Drawing Analyzer.
2. Never modify original drawing PDFs. All outputs go to `outputs/`.
3. Always confirm takeoff scope with the user before running the Construction Takeoff skill.
4. Mark every LOW confidence quantity. Every LOW confidence item needs manual verification before use in a bid.
5. Do not add rates or totals to takeoff output. The estimator fills those in.
6. If the Drawing Analyzer has not been run for this project, stop and tell the user to run it first.

---

## Confidence levels

**HIGH:** Confirmed by both text layer data and visual analysis. Sources agree.
**MEDIUM:** Visual analysis only, or a dimension calculation without direct confirmation.
**LOW:** Could not be confirmed from the drawings. Must be manually verified before use in a bid.
